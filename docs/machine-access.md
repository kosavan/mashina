# Ограниченный API и локальный MCP

Необязательный срез ветки 2.0. Основной гараж работает без интеграций. Ключи не являются заменой пользовательского сеанса: они открывают только выбранные автомобили и разрешённые операции.

## Включение и выпуск ключа

В приватном `.env` задайте `MASHINA_API_ENABLED=1`, затем выполните `docker compose up -d --build`. Изменение флага применяется при перезапуске приложения. По умолчанию значение 0. Для удалённого подключения нужен HTTPS; не публикуйте HTTP-порт домашнего сервера.

В «Настройки → API и интеграции» укажите название клиента, явно выберите автомобили и срок 1–365 дней (по умолчанию 90). Максимум десять действующих ключей и 50 автомобилей в одном ключе. Только исходный владелец автомобиля может выдать такой доступ; роль совместного владельца, водителя или администратора установки этого не заменяет. Новые автомобили автоматически не добавляются. В деморежиме реальные ключи не создаются.

По умолчанию разрешено чтение. Запись включается отдельным согласием: клиент сможет создавать, исправлять и удалять события и напоминания. Профили автомобилей, документы, аккаунты, банковское сопоставление, уведомления и резервные копии этим ключом недоступны. Обычные описания событий, категории, продавцы, названия деталей и артикулы читаемы и могут содержать личные сведения, которые вы туда внесли. Передавайте ключ только клиенту, которому доверяете эти данные.

Секрет показывается один раз. Сохраните его в менеджере паролей или приватном окружении клиента. При отказе браузера в копировании выделите поле и скопируйте вручную. В базе хранится SHA-256 проверка случайного 256-битного секрета; список ключей, аудит, обычный экспорт и локальный кэш приложения секрета не содержат. Если ответ выпуска потерялся, обновите список и отзовите неизвестное подключение, затем выдайте новый ключ: повторное получение прежнего секрета невозможно.

Управление доступом требует соединения с сервером. Отзыв, истечение срока, отключение пользователя, смена/сброс пароля или утрата исходного владения блокируют дальнейшие запросы. Смена пароля и отключение пользователя навсегда отзывают ключи; включение пользователя обратно их не восстанавливает. Выключение серверного флага блокирует все ключи. Запрос, авторизованный в транзакции до фиксации отзыва, может успеть завершиться; уже переданные клиенту данные отозвать нельзя.

## REST

Базовый путь `/api/machine/v1`; заголовок `Authorization: Bearer …`. Cookie-сеанс не является запасным способом входа сюда. Обратно, bearer не открывает обычный `/api/v1/state`, документы или административные маршруты. Не передавайте ключ в URL, CLI-аргументах, публичных конфигурациях и логах.

Авторизованный `/api/machine/v1/openapi.json` содержит только машинный контракт, bearer-схему и строгие модели событий/напоминаний. Полное описание: [контракт](../specs/008-machine-access/contracts/api.md).

| Метод | Путь | Результат |
|---|---|---|
| GET | `/vehicles` | Выбранные автомобили, краткие характеристики, подтверждённый текущий пробег |
| GET | `/vehicles/{id}/history` | События, limit 25/max100, next_cursor, фильтры search/kind/start/end |
| GET | `/vehicles/{id}/reminders` | Напоминания, limit25/max100, next_after |
| GET | `/vehicles/{id}/analytics` | Эксплуатационные расходы, пробег, топливо и графики; start/end/currency |
| POST | `/vehicles/{id}/mutations` | Запись/исправление/удаление события или напоминания при write-разрешении |

История сортируется по дате события и ID, от новых к старым. Исторические записи остаются на своей дате. Поиск до 200 символов — буквальное совпадение в описании, категории, продавце, названиях/артикулах позиций; `%` и `_` не являются wildcard. Курсор относится к автомобилю и фильтрам, но никогда не заменяет проверку прав. Даты: ГГГГ-ММ-ДД. Поиск SQLite LIKE по умолчанию регистрозависим для кириллицы. У напоминаний продолжение задаётся параметром `after=next_after`.

Аналитика использует ту же доменную модель, что приложение: учитывает показания пробега и границы полного бака до начала периода. Отсутствующие измерения не превращаются в ноль. Цена покупки/продажи и изменение стоимости не входят в этот эксплуатационный ответ. При истории свыше 20000 событий возвращается явная ошибка размера, без усечённых финансовых итогов; используйте приложение для такого архива. Первая страница 25/10000 проверяется с бюджетом одна секунда на тестовом оборудовании, без обещания такой скорости на каждом сервере.

Запрос записи содержит `operation_id` (стабильный UUID), `entity` (`event`/`reminder`), `id` (UUID записи), `action` (`upsert`/`delete`), `base_version` и `data`. Создание: base_version0; исправление/удаление: текущая версия. Удаление: пустой data. Повторяйте тот же UUID и неизменный запрос после потери ответа: сумма будет учтена один раз. Тот же ID с другим содержимым →409. Пространство операций изолировано по ключу и от браузерной очереди. Между разными ключами повтор одной бизнес-операции автоматически не распознаётся: используйте один ключ и стабильный ID для её повторов.

Суммы/литры/цена/количества передаются строками десятичных чисел, пробег — целым числом. Позиции имеют name, part_number, quantity, unit_price, discount. Топливо требует любые два значения liters/price/amount; одна финансовая запись. Неизвестные поля, включая вложенные, отвергаются. Нельзя передать owner_id, created_by, file IDs, банковские идентификаторы или флаг подтверждения коррекции пробега. Коррекции, нарушающие хронологию, подтверждаются человеком в приложении. Выполнение повторяемого напоминания также делается в приложении с фактическим пробегом: API не принимает доверенный completion-флаг.

Ошибки: 401 недействительный ключ/функция выключена;403 чужой автомобиль или недостаточно прав;409 конфликт версии/повтора;422 поля/период/размер истории;413 тело записи свыше256KiB. Каждое чтение, изменение и повтор заново проверяет ключ/пользователя/автомобиль внутри общей транзакции.

## MCP на стороне клиента

Адаптер запускается клиентом как дочерний процесс; постоянного MCP-порта или нового фонового сервиса нет. Из исходного каталога с установленными зависимостями запустите `python -m backend.machine_protocol`. В настройках клиента укажите эту команду и приватное окружение `MASHINA_SERVER_URL` (корень вашего HTTPS-сервера, без пути/параметров/логина) и `MASHINA_MACHINE_TOKEN` (выданный ключ). Секреты не помещайте в аргументы команды или публикуемый JSON. Локальная разработка допускает только HTTP с буквальным loopback-адресом, например `http://127.0.0.1:8000`; `localhost` и обычный LAN HTTP не допускаются.

Четыре инструмента: mashina_vehicles, mashina_history, mashina_reminders, mashina_analytics. Они выполняют только GET даже с ключом, разрешающим запись. Не принимают произвольные URL, пути, SQL или команды. Данные истории — пользовательский контент, а не инструкции для модели.

Поддержаны две явно проверенные версии: 2026-07-28 (params._meta с protocolVersion/clientCapabilities, server/discover, resultType complete) и 2025-11-25 (initialize → notifications/initialized). STDIO использует UTF-8 JSON-RPC по одной строке, не Content-Length framing. Инструменты имеют object-root structuredContent и текстовый JSON fallback. Не заявляются подписки, фоновые задачи, запросы к клиенту или универсальная совместимость со всеми клиентами. [Современный протокол](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning), [прежний lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle).

TLS проверяется системным доверенным хранилищем. Перенаправления и переменные HTTP_PROXY не используются. Максимум четыре запроса одновременно, десять секунд на HTTP,1MiB на строку/ответ/вывод. Закрытие STDIO отменяет работу и завершает процесс; отменённый запрос не выдаёт поздний ответ. stdout содержит только протокол; ошибки не показывают ключ. Это локальный STDIO-компонент над REST, а не удалённый OAuth MCP-сервер.

## Обновление и восстановление

Аддитивная миграция006 сохраняет историю и предыдущие банковские/notification-инварианты. Полный архив содержит проверочные хеши, scope, атрибуцию и квитанции операций, без plaintext ключей. При восстановлении все ключи отзываются, пользовательские сеансы сбрасываются, уведомления остаются приостановлены. Выдайте новые ключи после проверки восстановления. Архивы001–005 мигрируются с пустым набором машинных ключей. Destructive downgrade запрещён; используйте проверенный бэкап и прежний образ для отката.

Проверки: `pytest backend/tests/test_machine_access.py backend/tests/test_machine_protocol.py`, полный backend pytest, frontend `npm run check`, `npm test`, `npm run build`, `npm run test:e2e`. Протокольные тесты подключаются только к вымышленному локальному HTTP/TLS-серверу; реальные данные третьим лицам не передаются.
