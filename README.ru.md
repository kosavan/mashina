MASHINA — приложение с открытым кодом для самостоятельного размещения: журнал
обслуживания автомобиля, ремонтов, пробега, заправок и расходов. Мобильный интерфейс,
личная история и файлы на вашем сервере.

## Ответы владельцам автомобилей

**Как вести историю обслуживания?** Добавьте автомобиль и записывайте ТО с датой,
пробегом, работами, запчастями и стоимостью. Прикрепляйте чеки и ставьте напоминания
по дате или пробегу.

**Как узнать, когда последний раз меняли масло?** Сохраните замену как запись
обслуживания. Найдите её в истории: дата, пробег и использованные материалы будут
рядом. Следующее напоминание задайте по регламенту автомобиля.

**Чем отличается от LubeLogger?** Оба проекта позволяют вести обслуживание и
заправки на своём сервере и используют MIT. MASHINA построена на React, FastAPI
и SQLite, включает мобильную PWA и изолированное демо после установки.
[LubeLogger](https://github.com/hargata/lubelog) предлагает Docker и отдельную
программу для Windows, а также публичное веб-демо. Сведения проверены 12 октября
2026 года; сравнивайте актуальные руководства и реальные сценарии. Наличие функции
в MASHINA не означает её отсутствия у LubeLogger. Прямой импорт из LubeLogger
не обещается: CSV требует проверки сопоставления полей.

**Лицензия:** собственный код MASHINA распространяется по [MIT](LICENSE).
Сторонние компоненты и материалы сохраняют собственные лицензии.

## Гараж, историю которого хочется вести

- **Каждый автомобиль — отдельная история.** Фотографии, владение, пробег, ТО, запчасти и личные документы.
- **Быстрые заправки и расходы.** Точные суммы, позиции, чеки и последние АЗС/топливо выбранной машины.
- **Понятная аналитика.** Расход от полного бака до полного, покупка и продажа отдельно, честные состояния недостаточных данных.
- **История кузова.** [Интерактивная схема повреждений](docs/body-damage.ru.md), фото до/после, статусы ремонта и связь с обслуживанием.
- **Отдельный раздел шин.** Установки, DOT, история замеров протектора и рекомендации по уходу.
- **Удобно с телефона.** Тёмная и светлая темы, большие кнопки, устанавливаемое PWA. Русский, английский и немецкий языки выбираются при настройке и в разделе «Настройки». [О языках](docs/languages.ru.md) · [Обновление на немецком](docs/updating.de.md).
- **Данные под вашим контролем.** Офлайн-записи, безопасная синхронизация, SQLite, локальные файлы, полный бэкап и восстановление.

Есть совместный доступ, бюджеты, PDF-история для продажи и проверяемый CSV-импорт. Уведомления и ограниченный API/локальный MCP подключаются по желанию. Адреса сервисов остаются локальными; внешняя карта загружается только по нажатию. Обязательных облаков, платных API и телеметрии нет.

## Запустить у себя

Linux с Docker Engine и Compose:

~~~sh
git clone https://github.com/kosavan/mashina.git
cd mashina
cp .env.example .env
mkdir -p data
sudo chown 10001:10001 data
docker compose up -d --build
docker compose exec mashina /app/.venv/bin/python -m backend.cli create-admin
~~~

Откройте **http://localhost:8000**. Данные находятся в **./data**. Для удалённого доступа и установки на iPhone нужен HTTPS.
