# Plan: Global unit and currency settings (1.11.0)

- **Settings persistence (`backend/storage.py`)**: Validate `currency` (`^[A-Z]{3}$`), `distance_unit` (`km` | `mi`), `volume_unit` (`l` | `gal_us` | `gal_uk`), and `consumption_unit` (`l_100km` | `mpg_uk` | `mpg_us` | `km_l` | `l_100mi`) in `users.settings` mutations while preserving unknown/existing preference keys. Apply global currency and vehicle currency defaults when creating vehicles and vehicle-bound records if `currency` / `cost_currency` is omitted.
- **Domain & analytics (`backend/domain.py`, `backend/app.py`, `backend/output_locale.py`, `backend/reports.py`, `backend/bank_csv.py`)**: Compute fuel cycle and overall consumption according to `distance_unit`, `volume_unit`, and `consumption_unit`; expose unit metadata in `/api/v1/analytics`; reflect `distance_unit` in readable CSV and sale PDF reports; expand bank CSV currency allowlist to all 15 supported 2-decimal currencies.
- **Frontend UI & offline projection (`frontend/src/`)**: Add unit and default currency pickers in `SettingsPage`; propagate `defaultCurrency`, `distanceUnit`, `volumeUnit`, and `consumptionUnit` across `Views.tsx`, `Forms.tsx`, `Analytics.tsx`, `OwnershipTools.tsx`, `BodyDamage.tsx`, `BankImport.tsx`, and `offline.ts`; provide currency `<datalist>` and full currency dropdowns; translate all new strings across all 8 UI languages (`ru`, `en`, `de`, `zh`, `hi`, `es`, `ar`, `fr`) and output locales (`ru`, `en`, `de`).
- **Verification & release (`1.11.0`)**: Add backend unit/API tests and frontend unit/browser tests; run full test suites, doc checks, migration checks, secret scan, site build, and update `RELEASES.md`, `docs/roadmap.md`, `docs/roadmap.ru.md`, `docs/updating.md`, `docs/updating.ru.md`, `docs/updating.de.md`, and version metadata to `1.11.0`.
