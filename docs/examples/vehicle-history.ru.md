# Помогите проверить PDF с историей обслуживания автомобиля

Когда покупатель спрашивает, на каком пробеге меняли масло, колодки или тормозную жидкость, ответ часто приходится собирать по чекам и фотографиям. В MASHINA для этого есть PDF-отчёт из записей журнала. В нём видны даты, пробег и работы, а VIN, госномер и суммы можно оставить выключенными.

[Открыть пример PDF с вымышленным Volvo XC60](https://github.com/kosavan/mashina/blob/showcase/vehicle-history-pdf/docs/examples/mashina-primer-istorii-avto.pdf)

Ищем до пяти владельцев машин, которые готовы проверить этот сценарий. Откройте пример и представьте, что получили его от продавца. Что вы смогли понять с первого взгляда? Какой информации о работах вам не хватило? Если захотите проверить экспорт, запустите MASHINA и откройте демогараж. В карточке автомобиля выберите **«Отчёт для продажи»**.

Оставьте впечатления в комментариях. Для проверки достаточно демоданных. [Инструкция по установке](https://github.com/kosavan/mashina#quick-start)

MASHINA — открытый автомобильный журнал для запуска на своём компьютере или сервере. Проект создан с помощью ИИ и развивается по обратной связи пользователей.
