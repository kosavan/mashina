# Implementation plan

React/TypeScript/Vite and FastAPI/SQLite modular monolith remain unchanged. Extend validated JSON payloads additively, with old fields defaulting to unknown. No new daemon or mandatory cloud dependency.

## Constitution check
Data integrity, exact money, authenticated private events, explicit external requests, real measurements, Russian mobile UI and source-only publication are mandatory. Identity selection and video rendering follow the requested skills' explicit review checkpoints. No placeholder OCR or simulated map is shipped.

1. Reproduce first-impression/fuel defects, fix and exercise browser navigation.
2. Dedicated Tires navigation, validation, measurement UI and sourced age guidance; backend/frontend/browser tests.
3. Local service location metadata, explicit external map view and tests.
4. Vehicle-specific fuel defaults and truthful capture instructions.
5. Logo concepts and Hyperframes review artifact; English/Russian README with verified feature claims.

## Validation
