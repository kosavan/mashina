# Языки интерфейса

Русский · [English](languages.md) · [Deutsch](../README.de.md)

В MASHINA 1.8.0 доступны русский, английский, немецкий, китайский (упрощённый), хинди, испанский, арабский и французский. Для арабского используется направление справа налево. По умолчанию
остаётся русский. Язык выбирается до настройки/входа/демо или в
**Настройки → Язык приложения** (на немецком **Einstellungen → App-Sprache**).

Локальный выбор переживает перезагрузку. Настройка аккаунта сохраняется через
существующую надёжную офлайн-очередь и синхронизируется при подключении.
Меняется только поле языка, остальные предпочтения сохраняются. Обновляйте
интерфейс и сервер вместе: до 1.7 сервер принимает RU/EN, в 1.7 — ещё DE,
а в 1.8 — все восемь языков. Старые
поддерживаемые запросы и ожидающие финансовые операции остаются совместимыми.

Переведены навигация, формы, подписи доступности, известные сообщения проверки,
аналитика, повреждения кузова и представление изолированного демогаража.
Даты и числа форматируются для выбранного языка; немецкий использует `de-DE`. Новые каталоги загружаются по выбору, все публичные каталоги кэшируются для офлайн-работы. Валюты, единицы, точные суммы, ID,
пользовательские категории, названия, заметки и файлы не меняются. Перевод демо
не переписывает его сохранённые записи или канонические финансовые категории.

В 1.9 PDF, читаемый CSV и общие внешние уведомления используют язык аккаунта
RU/EN/DE; для остальных языков интерфейса — английский. Пользовательский текст,
машинный JSON и прежний CSV не меняются. См. [границы локализации](ocr-results-archives.ru.md). OCR использует
поставляемые русские/английские данные Tesseract: выбор языка интерфейса не добавляет
языки распознавания. Во время работы приложение не обращается к сервисам перевода.
