# Проверяемый импорт банковских CSV

«Обслуживание → Импорт → Проверить выписку» — необязательный локальный инструмент.
Подключения к банку, логина, номера карты и платных API нет. Работает и в изолированном
демогараже. Оригинал CSV не сохраняется. Используйте копию выписки и выбирайте только
операции, относящиеся к автомобилю.

## Формат

UTF-8 (с BOM или без) либо явно выбранная Windows-1251; запятая, точка с запятой
или табуляция. Максимум 2 МБ, 1 000 строк и 50 столбцов. Заголовки непустые и разные,
число ячеек соответствует заголовкам. Поддерживается обычное CSV-кавычкование.

Обязательные столбцы: дата, сумма со знаком, описание. Необязательные: стабильный ID
операции банка и код валюты. Формат даты выбирается явно: `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`.
Укажите, какой знак означает расход. Суммы допускают точку/запятую и корректные группы
тысяч через пробел; максимум два знака после десятичного разделителя. RUB, EUR, USD
хранятся точно в минимальных единицах, без конвертации и смешивания итогов.

XLSX/PDF, отдельные столбцы дебета/кредита, возвраты и банковские переводы в этом срезе
не поддерживаются. Входящую/нулевую строку можно явно пропустить, расход из неё создать
нельзя. Некорректную строку оставьте без выбора и исправьте исходный файл.

## Проверка

1. Выберите автомобиль, файл, кодировку и разделитель. Чтение столбцов возвращает
   только заголовки и число строк, без примеров чужих банковских полей.
2. Сопоставьте нужные столбцы и выберите личный источник. Для следующих выгрузок того
   же счёта используйте тот же источник; название — понятная метка без реквизитов.
3. Проверьте карточки. Совпадения имеют точно такую же сумму/валюту и дату в пределах
   трёх дней. Показываются пять ближайших и полное число совпадений. Автовыбора нет.
4. Создайте новый расход, свяжите с существующим либо пропустите. Связь не меняет
   исходную заправку/работу/расход и не добавляет деньги. Одна банковская строка может
   связываться с одной записью; разделение платежа на несколько событий пока отсутствует.
5. Проверьте итог и подтвердите. Строки без выбора не сохраняются. Изменившееся
   совпадение, потерянные права или другая ошибка отменяют весь выбранный набор.
   Решения остаются на экране для исправления; повтор ответа не дублирует суммы.

Описание нового расхода становится частью обычной истории автомобиля, доступной
его участникам. Перед созданием уберите из него личные сведения. Источник, ID банка
и исходные выбранные банковские поля остаются приватными для импортировавшего пользователя.

## Повторы и ограничения идентичности

Стабильный ID банка действует внутри личного источника независимо от автомобиля.
Повторная выгрузка не создаст второй расход даже после удаления связанной записи.
Изменённая сумма/дата/описание с тем же ID — конфликт, исходная история не перезаписывается.

Если банк не выдаёт ID, только полностью тот же файл и номер строки доказывают точный
повтор. В другом файле равные дата/сумма/описание — предупреждение, а не доказательство:
две одинаковые покупки могут быть настоящими. Перед новой записью нужно явно подтвердить,
что это отдельная операция. Изменение порядка строк, кодировки или несопоставленных
столбцов также меняет файл. Не создавайте новые источники ради обхода предупреждений.
Разные пользователи/источники изолированы; глобального сравнения банковских операций нет.

## Приватность, офлайн и восстановление

Сервер хранит только сопоставленные поля предпросмотра. Он доступен 30 минут, затем
не может быть подтверждён; истёкшие предпросмотры очищаются при следующей проверке.
Хранятся не более трёх активных предпросмотров пользователя. Фонового таймера нет.
Браузер не сохраняет выписку/решения в IndexedDB; закрытие или перезагрузка теряет
неподтверждённый черновик. Для проверки и подтверждения нужна связь со своим сервером;
сначала синхронизируйте обычные ожидающие записи.

Личный журнал подтверждений скачивается отдельно внутри инструмента. Он содержит
банковские поля, храните его приватно. Обычный общий JSON/CSV-экспорт истории, отчёт
для продажи и уведомления не включают банковский журнал. Полный административный ZIP
содержит всю базу, включая приватные подтверждения: защищайте резервные копии.

Миграция 005 добавляет таблицы без изменения финансовой истории. Проверенное
восстановление сохраняет источники, подтверждения и операции; все предпросмотры
аннулируются, сеансы закрываются, внешние уведомления остаются приостановлены.
Архивы схем 001–004 поддерживаются с последующей миграцией. Перед обновлением сохраните
полный ZIP на другом диске; для отката старого приложения используйте совместимый
архив до обновления, а не разрушительное понижение схемы.
