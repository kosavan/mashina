# Мобильные приложения

[English](mobile-clients.md) · Русский

## Android APK и iOS IPA

Приложения открывают привычный интерфейс MASHINA на телефоне. Укажите
HTTPS-адрес своего сервера и войдите в существующий аккаунт. Минимальные
версии системы — Android 8.0 и iOS/iPadOS 16.

1. Ищите мобильные пакеты и суммы SHA-256 в
   [релизе на GitHub](https://github.com/kosavan/mashina/releases). Проверочные
   сборки находятся в разделе **Artifacts** на странице
   [сборки мобильных пакетов](https://github.com/kosavan/mashina/actions/workflows/mobile.yml).
2. На Android откройте подписанный APK. Если система запросит разрешение,
   разрешите установку для программы, через которую открыли файл.
   У проверочного APK отдельный идентификатор и временная подпись.
   Синхронизируйте ожидающие записи перед заменой проверочной сборки.
3. На iPhone или iPad подпишите IPA своим сертификатом и профилем
   подготовки, который разрешает установку на ваше устройство. Для
   обновления сохраняйте подпись и идентификатор приложения, если инструмент
   подписи позволяет. IPA предназначен для самостоятельной подписи и установки.
4. Откройте MASHINA, нажмите «Сервер» и введите адрес вида
   `https://mashina.example.org`. Устройство должно доверять сертификату
   сервера. Для закрытого сервера подключитесь к его локальной сети или VPN.
   После проверки адреса войдите в свой аккаунт.

Перед переходом с PWA синхронизируйте ожидающие изменения. У установленного
приложения собственное веб-хранилище и отдельный вход. Синхронизированные записи
доступны через тот же сервер. Для проверенной работы офлайн используйте PWA.
Холодный запуск без сети и push-уведомления в мобильных пакетах ещё предстоит
проверить. На Android отчёты, которые веб-интерфейс формирует прямо на
устройстве, сохраняйте через браузер.

## Сборка и выпуск

- Для Android нужны Java 17, Python 3.11 или новее, платформа Android SDK 35
  и Build Tools 35.0.1. Запустите `bash mobile/build-android.sh preview` в Linux.
  Скрипт проверит подпись, идентификатор пакета и точку запуска.
- Для iOS нужны macOS с Xcode и Python 3.11 или новее. Запустите
  `bash mobile/build-ios.sh`. Скрипт проверит архитектуру устройства,
  идентификатор пакета и отсутствие подписи и профиля.
- Оба скрипта складывают пакеты в `dist/mobile/`. Для каждой версии Android
  используйте одно защищённое хранилище ключей. Ручной запуск сборки из
  `main` использует секреты репозитория `MASHINA_ANDROID_KEYSTORE_BASE64`,
  `MASHINA_ANDROID_STORE_PASSWORD`, `MASHINA_ANDROID_KEY_ALIAS` и
  `MASHINA_ANDROID_KEY_PASSWORD`. Сборка прикрепляет оба пакета и контрольные
  суммы к существующему стабильному релизу после прохождения обеих проверок
  на точном коммите тега. У каждой платформы свой проверочный артефакт.
- Перед распространением установите релизный APK и самостоятельно подписанный
  IPA на физические устройства. Проверьте отказ при недоверенном сертификате
  и перенаправлении проверки сервера. Войдите, откройте доступный автомобиль,
  сохраните заправку и после перезапуска убедитесь, что она появилась на сервере
  один раз. Проверьте загрузку вложения и сохранение архива, переключение двух
  серверов, отказ при ошибочном новом адресе и обновление поверх установленной
  версии с прежней подписью и идентификатором.

Порядок сохранения данных сервера и ожидающих записей описан в
[руководстве по обновлению и откату](updating.ru.md).

## PWA

Откройте свой сервер MASHINA по HTTPS. На iPhone или iPad в меню Safari
«Поделиться» выберите «На экран Домой». На Android в меню браузера выберите
«Установить приложение» или «Добавить на главный экран». Для работы офлайн
сначала войдите в аккаунт при подключении к серверу. Офлайн-изменения
останутся в очереди на устройстве до синхронизации.

## План клиента с прямым доступом к API

Будущий клиент со встроенным интерфейсом сможет использовать
[общий транспорт](../frontend/src/api.ts) и сохранять идентификаторы операций,
версии и точные десятичные значения. В план входят подключение устройства
с подтверждением, отзыв сессии, хранение учётных данных в Keychain или
Android Keystore, офлайн-очередь по адресу и аккаунту и съёмка чеков.
[Машинный API](machine-access.ru.md) предназначен для автоматизации.
