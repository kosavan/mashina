# MASHINA Dusk

Hallmark 2.0 full visual redesign, requested 2026-10-26. Shared system for the
application, public GitHub Pages site and repository product imagery.

## Identity and material

Keep MASHINA's existing M symbol and locally hosted Manrope. The logo's lime is
an identity detail; operational controls use restrained periwinkle, and apricot
marks waiting or upcoming work. Preserve product facts, actions and user data.
Real application captures show only the isolated fictional demo garage.

## Dusk surfaces

Slate canvas, warm off-white text, smoked glass with a subtle lit upper edge.
Glass is reserved for navigation, overlays and independent product surfaces;
interior rows use space and rules. The light counterpart uses warm bone surfaces
and dark ink with the same hierarchy. Local landscape photography gives the
welcome screen and public hero an actual setting. Keep a readable solid fallback
when backdrop filtering is unavailable.

## Typography and interaction

Use theme tokens for all colors and fonts. Keep headings in one color and weight;
sentence-case labels, tabular figures, clear focus rings and 44px touch targets.
Use existing shell, routes, form fields and handlers. Preserve safe areas,
right-to-left layout, 360px layouts and reduced-motion preferences. No decorative
loops. Interactive elements must remain usable without backdrop filtering.

## Scope and compatibility

This is a presentation and bundled-assets change. No schema, API, money,
authorization, settings-key or offline-queue changes. Deployment and rollback
procedures remain the existing ones. No owner-server deployment is included.
Do not replace private owner photographs or mutate stored attachment bytes.
